# xpns — Mobile Frontend

React Native (Expo) client for the Treasure Chest Records backend.

Before working in this repo, read:
- [`.agent/frontend_implementation.md`](.agent/frontend_implementation.md) — decisions made and
  why, what's actually implemented vs. still open, phase-by-phase. Update it as part of any
  non-trivial change; it is the source of truth for status, not this file.
- [`.agent/backend_contract.md`](.agent/backend_contract.md) — the backend's request/response
  contract this app codes against. Where the two disagree, `frontend_implementation.md` wins (it
  documents corrections verified against the running backend).
